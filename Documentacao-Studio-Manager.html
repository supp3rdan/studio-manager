🎯 Visão Geral

👩‍💼

Para o Profissional

Dashboard completo: agenda, clientes, serviços, disponibilidade e financeiro.

💁

Para o Cliente

Portal público: busca o profissional, escolhe serviço e agenda online sem complicação.

🔒

Seguro por Design

RLS no banco garante isolamento de dados. RPCs SECURITY DEFINER para leitura pública controlada.

📱

PWA

🟩

📄

jsPDF

Exportação de relatório de agendamentos em PDF diretamente no browser.

🔐 Segurança

⚠️
Nunca exponha a service_role key no browser. Apenas as variáveis NEXT_PUBLIC_* são seguras para o client-side.

Row Level Security (RLS)

Cada usuário só acessa seus próprios dados. O banco impõe isso automaticamente, independente da aplicação.

TabelaPolíticaRegra
perfisperfis_read_ownauth.uid() = id
perfisperfis_public_read_profissionaistipo_usuario = 'profissional' (público)
servicosservicos_select/insert/update/deleteauth.uid() = user_id
agendamentosagendamentos_selectauth.uid() = user_id
agendamentosagendamentos_select_clienteauth.uid() = cliente_user_id
indisponibilidadesindisponibilidades_select/insert/update/deleteauth.uid() = user_id
indisponibilidadesindisponibilidades_select_publicotrue (cálculo de slots)

RPCs SECURITY DEFINER

Funções que rodam com privilégio elevado mas retornam apenas dados de um profissional específico — sem vazar dados de outros.

FunçãoPropósitoAcesso
get_servicos_do_profissional(user_id)Lista serviços ativos de um profissionalanon + authenticated
get_horarios_disponiveis(prof_id, data, duracao)Calcula slots livres (07h–22h)anon + authenticated
get_agendamentos_ocupados(prof_id, data)Horários com agendamentos ativosanon + authenticated
criar_agendamento_publico(...)Cria agendamento + cliente com segurançaanon + authenticated
handle_new_user()Cria perfil automaticamente no cadastrotrigger interno

⚙️ Configuração Local

1. Clone e instale

git clone https://github.com/supp3rdan/studio-manager.git
cd studio-manager
npm install

2. Variáveis de ambiente

Crie o arquivo .env.local com:

NEXT_PUBLIC_SUPABASE_URL
URL do seu projeto Supabase (ex: https://xxxx.supabase.co)
NEXT_PUBLIC_SUPABASE_ANON_KEY
Chave anônima pública do Supabase

3. Execute as migrations no Supabase SQL Editor

Execute em ordem, uma por vez:

#ArquivoO que cria
001001_initial_schema.sqlTabelas clientes, serviços, agendamentos + RLS
002002_perfis_e_portal_cliente.sqlTabela perfis, trigger de criação, portal público
003003_fix_agendamento_publico.sqlCorreções no agendamento público
004004_disponibilidade_e_promocoes.sqlIndisponibilidades, duração, promoções, horários
005005_pagamento_misto.sqlPagamento misto (campo TEXT)
006006_horarios_07_as_22.sqlHorários 07h–22h
007007_fix_servicos_rls_e_duracao.sqlCorreção RLS + duração 60min Cílios/Depilação
008008_fix_servicos_publico_rls.sqlRPC get_servicos_do_profissional
009009_agendamentos_ocupados_e_login_obrigatorio.sqlRPC get_agendamentos_ocupados

4. Inicie o servidor

npm run dev
# Acesse: http://localhost:3000

📜 Histórico de Migrations

001 — Schema Inicial

Tabelas clientes, servicos, agendamentos. RLS básico. Triggers updated_at.

002 — Perfis e Portal do Cliente

Tabela perfis com código único de 4 dígitos. Trigger handle_new_user. cliente_user_id. RPC criar_agendamento_publico.

003 — Correções Agendamento Público

Correções na função de criação de agendamento. Fuso horário America/Sao_Paulo.

004 — Disponibilidade e Promoções

Tabela indisponibilidades. Campos duracao_minutos, preco_promocional, promocao_ativa. RPC get_horarios_disponiveis (07h–22h).

005 — Pagamento Misto

Campo forma_pagamento muda de ENUM para TEXT. Suporta combinações como "Pix + Dinheiro".

006 — Horários 07h às 22h

Janela de atendimento expandida de 08h–17h para 07h–22h.

007 — Correção RLS e Duração

Remove política que vazava serviços entre profissionais. Cílios e Depilação: duração padrão 60 min.

008 — RPC Serviços Públicos

Cria get_servicos_do_profissional(user_id) (SECURITY DEFINER) para clientes lerem serviços com segurança.

009 — Horários Ocupados e Login Obrigatório

RPC get_agendamentos_ocupados. Slots com agendamentos ativos ficam ocultos para clientes. Login exigido para agendar.
